# 5. Śledzenie zadań

**Opis:** Commituj z conventional commits (cz-git), linkuj issue przez SC-XXX tagi, generuj changelog automatycznie.

## Quick Start

1. **Zainstaluj Husky hooks:** `yarn prepare` (już powinno być)
2. **Commituj przez wizard:** `yarn commit`
3. **Format wybierz:** type → description → SC-XXX (opcjonalnie)
4. **Changelog:** Automatyczny przy release (`yarn release`)

## Concept

Next.js 15 Template to kompleksowe rozwiązanie startowe do tworzenia nowoczesnych aplikacji webowych z gotową architekturą, narzędziami i konfiguracją.

## Problem

- **Czasochłonny setup** – Konfiguracja Next.js + TypeScript + testów zajmuje dni
- **Rozproszona dokumentacja** – Kluczowe ustalenia porozrzucane po plikach
- **Brak automatyzacji** – Ręczne CI/CD, kontrola jakości, release
- **Brak wsparcia AI** – Szablon nie przygotowany do pracy z agentami

## Why?

Template został stworzony, aby rozwiązać problemy związane z czasochłonnym setupem, rozproszoną dokumentacją i brakiem automatyzacji w procesie tworzenia nowoczesnych aplikacji webowych.

## Solution

- ✅ **Setup w < 10 minut** – kompletna konfiguracja Next.js 15 + React 19 + TypeScript
- ✅ **Memory Bank dla AI** – wszystkie ustalenia w jednym miejscu
- ✅ **Automatyczne workflow** – CI/CD, code quality, release gotowe
- ✅ **Modularna architektura** – szybka adaptacja i customizacja
- ✅ **Spójność narzędzi** – ESLint, Prettier, Husky skonfigurowane
- ✅ **Integracja Linear** – automatyzacja workflow z taskami

## Capabilities

### Modern Stack

- **Next.js 15** + **React 19** + **TypeScript** + **Turbopack**
- **Tailwind CSS 4** + **CVA** + **shadcn/ui** + **Radix UI**

### Developer Experience

- **Memory Bank** – dokumentacja dla AI/agentów
- **Automatyczne workflow** – CI/CD, Git hooks, Linear integration
- **Code quality** – Dual ESLint, Prettier, TypeScript strict
- **Testing** – Jest + Playwright + Storybook
- **Analysis** – Knip, Madge, Bundle Analyzer

### AI & Agent Integration

- **Memory Bank** – wszystkie ustalenia w dedykowanej strukturze dla AI
- **Testing Infrastructure** – Jest + Playwright + Storybook jako klucz do kontroli jakości z AI
- **Automated Quality Gates** – ESLint + TypeScript + Git hooks dla weryfikacji generowanego kodu
- **Domain Structure** – organizacja dokumentacji dla szybkiego generowania kodu przez agenty

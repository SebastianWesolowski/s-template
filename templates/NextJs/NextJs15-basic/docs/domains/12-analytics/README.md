# 12. Analytics

2. **Przejdź do [Technical Guide](technical.md)** - implementacja i setup
3. **Skonfiguruj Google Analytics** - [`tech-google-analytics.md`](tech-google-analytics.md)
4. **Skonfiguruj HotJar** - [`tech-hotjar.md`](tech-hotjar.md)
5. **Skonfiguruj Umami** - [`tech-umami.md`](tech-umami.md)
6. **Uruchom analytics** - `npm run dev` i sprawdź w konsoli

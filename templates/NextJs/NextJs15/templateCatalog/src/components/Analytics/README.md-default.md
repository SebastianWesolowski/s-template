# Analytics Component

A modular analytics integration component that supports multiple analytics providers (Google Analytics, HotJar, and Umami) for tracking user behavior and website performance.

## Features

- 🔍 Google Analytics 4 integration
- 🔥 HotJar session recording and heatmaps
- 📊 Umami analytics support
- 🚫 Disabled in development environment
- 🦥 Lazy loading of analytics scripts
- ⚡ Optimized for performance with proper script loading strategies

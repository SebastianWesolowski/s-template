# 14. Workflow

**Opis:** System workflow oparty na Git-based development z automatycznymi procesami, zapewniający spójny i wydajny proces rozwoju aplikacji.

## Quick Start

1. **Przeczytaj [Overview](overview.md)** - zrozum koncepcję workflow
2. **Przejdź do [Technical Guide](technical.md)** - setup i konfiguracja
3. **Skonfiguruj Git hooks** - `.husky/pre-commit`, `.husky/commit-msg`
4. **Ustaw CI/CD** - GitHub Actions workflows
5. **Zdefiniuj branching strategy** - feature, hotfix, release branches

# 15. Deployment

**Opis:** Automatyzacja procesu budowania i wdrażania aplikacji z wykorzystaniem GitHub Actions i Semantic Release, zapewniająca bezpieczne i niezawodne wdrożenia na różnych środowiskach.

## Quick Start

1. **Przeczytaj [Overview](overview.md)** - zrozum koncepcję build & deploy
2. **Skonfiguruj Secrets** - [`tech-github-actions-release.md#konfiguracja-tokenów`](tech-github-actions-release.md#konfiguracja-tokenów)
3. **Skonfiguruj Permissions** - [`tech-github-actions-release.md#workflow-permissions`](tech-github-actions-release.md#workflow-permissions)
4. **Uruchom deployment** - `git push origin main`

# 2. Personalizacja szablonu

**Opis:** Inteligentny system personalizacji szablonu z automatycznym zastępowaniem placeholderów, konfiguracją projektu i dostosowywaniem do specyficznych potrzeb.

## Quick Start

1. **Przeczytaj [Overview](overview.md)** - zrozum koncepcję customization i filozofię placeholder system
2. **Przejdź do [tech-customize.md](tech-customize.md)** - kompletny przewodnik po customization
3. **Skonfiguruj placeholdery** - ustaw wartości w [`tools/customize/customize.config.ts`](../../tools/customize/customize.config.ts)
4. **Uruchom customization** - `yarn customize`
5. **Zweryfikuj wynik** - sprawdź czy wszystkie placeholdery zostały zastąpione

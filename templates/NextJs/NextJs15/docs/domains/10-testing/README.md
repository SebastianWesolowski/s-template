# 10. Testing

**Opis:** Kompletna strategia testowania z test pyramid, automatyzacją i integracją narzędzi testingowych w development workflow.

## Quick Start

1. **Przeczytaj [Overview](overview.md)** - zrozum koncepcję testing
2. **Przejdź do [Technical Guide](technical.md)** - implementacja i setup
3. **Skonfiguruj Jest** - [`tech-jest.md`](tech-jest.md)
4. **Skonfiguruj Playwright** - [`tech-playwright.md`](tech-playwright.md)
5. **Skonfiguruj Storybook** - [`tech-storybook.md`](tech-storybook.md)
6. **Skonfiguruj Ngrok** - [`tech-ngrok.md`](tech-ngrok.md) - external testing
7. **Uruchom testy** - `yarn test` (dla E2E użyj `yarn test:e2e:ui` lub `yarn playwright test`)
